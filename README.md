# Navaneet Systems - Official Web Application

The official digital presence for **Navaneet Systems**, a premier office automation and IT solutions provider based in Hubli, India[cite: 1, 2]. This application serves as a high-performance storefront and service portal for their 31+ year legacy of business excellence[cite: 1, 2].

## 🏢 Business Overview
Navaneet Systems is an authorized dealer for global brands like **Canon** and **HP**, specializing in:
*   **Office Automation:** Advanced photocopiers and multi-function printers[cite: 1, 2].
*   **IT Infrastructure:** Laptops, desktops, scanners, and servers for SMEs and government institutions[cite: 1, 2].
*   **Professional Photography:** DSLR and Mirrorless camera gear and lenses[cite: 1, 2].
*   **Technical Services:** Annual Maintenance Contracts (AMCs) and specialized repair services[cite: 1, 2].

## 🚀 Tech Stack
*   **Framework:** Next.js (App Router)
*   **Styling:** Tailwind CSS (Mobile-first, responsive design)
*   **Animations:** Framer Motion (Scroll-reveal and interactive UI transitions)
*   **Icons:** Lucide React / React Icons
*   **Deployment:** Vercel (Optimized for Next.js)

## ✨ Key Features
*   **Responsive UI:** Optimized for all screen sizes, from mobile devices to large desktops.
*   **Interactive Product Catalog:** Categorized listings for Photocopiers, IT Hardware, and Cameras[cite: 1, 2].
*   **Service & Support Portal:** Dedicated sections for AMC inquiries and repair service workflows[cite: 1, 2].
*   **Trust Indicators:** Dynamic client testimonial grids and authorized partner branding (Canon, HP, Epson)[cite: 1, 2].

## 🛠️ Getting Started

### Prerequisites
*   Node.js 18.x or later
*   npm or pnpm

### Installation
1.  Clone the repository:
    ```bash
    git clone https://github.com/your-username/navaneet-systems-web.git
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run the development server:
    ```bash
    npm run dev
    ```
4.  Open [http://localhost:3000](http://localhost:3000) to view the application.
